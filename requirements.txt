# Every line caps the next major version. Lower bounds alone ("fastapi>=0.139")

# the app stops working for reasons that have nothing to do with your changes —
# sentence-transformers and torch both have a history of exactly that.
#
# These are ranges, not exact pins, because torch resolves differently per
# platform and a single pinned file can't be right everywhere. For a fully
# reproducible install, generate a lockfile on your own machine:
#
#     make lock        # writes requirements.lock.txt with exact versions
#     make install-locked
#
# Regenerate it whenever you change this file.

# torch: on Windows, force the CPU-only build. The default Windows torch wheel
# now ships Intel's torch_xpu.dll, which fails to load on many machines with
# "WinError 127: The specified procedure could not be found" — that crashes the
# embedding backend and silently drops semantic search back to keywords. This
# app only ever runs embeddings on the CPU, so the CPU build is all it needs
# (and it's ~10x smaller to download). Other operating systems are unaffected:
# the marker skips this line and torch installs normally via sentence-transformers.
# The extra index is where pip finds the +cpu wheels. See the README's
# Troubleshooting section if you already installed the broken wheel.
