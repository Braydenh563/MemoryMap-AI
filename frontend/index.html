                  Settings

                  Ollama powers the chat answers and auto-filing. Install it from ollama.com, start it, and this screen will light up. Capturing notes and keyword search work fine without it.

                  Chat model (answers your questions — switches instantly)

                  Utility model (filing, digest & writing fixes)

                  Quick background jobs run on this model, so a big slow chat model isn't tied up categorising every note. Point it at a small fast model (e.g. llama3.2) and let a bigger one answer your questions. Leave as “Same as chat model” to keep it simple.

                  Search engine (how your notes are understood)

                  Pick a dedicated embedding model (e.g. nomic-embed-text) — chat models can't create embeddings. Changing this re-reads every note so search keeps making sense — it runs in the background and search falls back to keywords until it finishes.
