        How to use this map
        
                  
          Solid lines are links you made, dashed lines are trains of thought,
          dotted lines are notes that mean similar things. Hover a note to
          spotlight its connections, drag to arrange, scroll or use the buttons
          to zoom, click a note to edit it right here, double-click to pin it in
          place, and click a legend colour to hide that category. Double-click
          empty space to add a note there. Gravity and Spread reshape the layout.
          Drop one note onto another to link them, and use
          Trace to see how any two notes connect.

                                          Let the AI search the web
                                          
            

            
                                          Which engine answers
                                          
            
                                          
            
                                          

            
                                          Your SearXNG instance
                                          
            
                                          
              
              
              
            
                                          
            
                                          
            
                                          
              SearXNG is the recommended way to search. It is a
              self-hosted search engine that MemoryMap can install and run for
              you in one click — you don't need Docker, an account, or any
              setup of your own. It gives better results than scraping
              DuckDuckGo, it can't be rate-limited the way scraping can, and
              the query never leaves your own network. It has to be on this
              machine or your own network — MemoryMap won't send searches to
              somebody else's instance, and the one it runs for you listens on
              127.0.0.1 only.
            
                                          
            
                                          
              
                                          
                Let MemoryMap run SearXNG
                Checking…
              
                                          
              
                                          
                MemoryMap can start and stop SearXNG for you — settings and the
                JSON API are configured automatically, so there's nothing to
                edit.
              
                                          
              
                                          
              
              
                                          
              
                                          
                
                
                
                
              
                                          
              
              
              
              
              
                                          
              
              
                                          
                What SearXNG reported
                
                                          
              
                                          
            
                                          
            
                                          
              Prefer to run it yourself?
              
                                          
                SearXNG is a separate service, so MemoryMap runs it beside
                itself rather than inside itself. If you'd rather drive it
                yourself, it's a single command with Docker:
              
                                          
              
                                          docker run -d --name searxng -p 8888:8080 \
  -e "SEARXNG_BASE_URL=http://localhost:8888/" \
  -v searxng:/etc/searxng searxng/searxng
                                          
              
                                          
                It must return JSON, so add - json under
                search.formats in its settings.yml, then
                restart it. Come back here and hit Auto-detect —
                MemoryMap checks the usual ports and fills this in for you.

                Your current password is asked for even though you're already

                                                  Sessions
                                                  
              
                                                  
                Unlocking issues a token that lives in memory only, so
                restarting the app locks it again. Changing your password ends
                every other session.
              
                                                  
              
                                                  
                
              
                                                  
            
                                                  

            
                                                  
              
                                                  If you forget your password
                                                  
              
                                                  
                There is no reset link, on purpose — one inside an app you're
                locked out of would just be a way in for anyone at the
                keyboard. Run this in a terminal instead:
              
                                                  
              
                                                  python -m memorymap --reset-password
                                                  
              
                                                  
                It asks you to confirm, then clears the password so you can set
                a new one. Your ordinary notes are not encrypted
                and come back untouched. Private notes are —
                their key is derived from your password, so without it they
                cannot be recovered by anyone, and the reset loses them. The
                command tells you how many you have before you confirm.

                                                    Help & guide
                                                    
              
            
                                                    
            
                                                    A quick reference to what each part of MemoryMap does. Click a topic to expand it.
                                                    
            
                                                    
              
                                                    
                📝 Capturing notes
                
                                                    In the Notes tab, type anything into “Capture a thought” and Save. A local AI files it into a category and suggests tags — you can always re-file or edit. Use a template, dictate with 🎙, sketch with 🎨, or let ✨ Improve proofread it first.
                                                    
              
                                                    
              
                                                    
                💬 Asking & chatting
                
                                                    “Ask your notebook” (Notes tab) and the Chat tab both answer from your saved notes. Turn on Agent mode to let the assistant use its tools — searching and reading your notes, opening a web page, creating, tagging, linking and organising. Destructive actions always ask first. Save, rename, and switch between conversations in the sidebar.
                                                    
              
                                                    
              
                                                    
                ⚡️ Skills
                
                                                    Skills are one-click requests above the chat box (e.g. “Summarise my week”). Add your own in Settings → Skills; a skill can use the AI’s tools so it actually does the work, not just describes it.
                                                    
              
                                                    
              
                                                    
                🕸 Graph
                
                                                    The Graph tab shows your notes as a network — links, threads, and (optionally) AI similarity lines. Search to highlight, drag to rearrange, toggle categories in the legend, and use the zoom controls to explore.
                                                    
              
                                                    
              
                                                    
                ⏰ Reminders
                
                                                    The Reminders tab groups items by Overdue / Today / Upcoming / Done. Set a priority, snooze, edit inline, or make one recurring. Notifications fire while the app is open.
                                                    
              
                                                    
              
                                                    
                📊 Dashboard
                
                                                    The Dashboard is your at-a-glance home: streaks, stats, pinned notes, reminders, a weekly digest, and more. Click “Edit layout” to show/hide and rearrange widgets — your layout is remembered.
                                                    
              
                                                    
              
                                                    
                🎨 Appearance
                
                                                    Settings → Appearance controls theme (light/dark/system), accent colour, fonts, density, glass effects, and the animated background. High-contrast and reduce-motion options are there for comfort and accessibility.
                                                    
              
                                                    
              
                                                    
                ⌨ Keyboard shortcuts
                
                                                    Press ? any time for the full list, or Ctrl/⌘+K to open the command palette and jump anywhere or search your notes.
