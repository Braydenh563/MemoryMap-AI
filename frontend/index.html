        Capture a thought

        A note is plain text. These few things do something extra:

        • [[its first few words]] — links to another note. Start typing [[ and a list of your notes appears; pick one to complete it. The link becomes a clickable chip on the saved note.
        • # A title on the first line becomes the note's title — the same thing the "Optional title" box above writes for you.
        • **bold**, *italic*, `code`, ~~struck~~, ==highlight== (or ==green|highlight== — also blue, pink, purple, orange; or select the words and use the ⋯ button), [text](url) and $x^2$ all render on the saved note.
        • tag: is for the filter box, not here — tags go in the tags field below, comma separated.

        Two things worth knowing, because they are easy to assume and both untrue:

        • There is no / command menu in this box. Pressing / anywhere you are not typing jumps to the search box; inside a document, Ctrl+/ comments the line. Neither is a note-composer command.
        • Headings beyond the first line, lists, tables, fenced code and > [!tip] callouts are stored faithfully but are not rendered on a note card — a note list rendered that way gets very tall very fast. They do render in the document editor.

          Write with the AI

          Type whatever's in your head — half sentences are fine. The AI turns it into a note. Edit the draft, add more thoughts, and it folds them in without undoing your changes. Your own words stay in the box: nothing here overwrites what you typed, and ↩ Undo steps back through every AI pass. This is the one part of the app that needs the local AI running — with it off, the Draft button is disabled and everything else on this tab still works.

                                                      Which engine answers
                                                      
            
                                                      
            
                                                      

            
                                                      Your SearXNG instance
                                                      
            
                                                      
              
              
              
            
                                                      
            
                                                      
            
                                                      
              SearXNG is the recommended way to search. It is a
              self-hosted search engine that MemoryMap can install and run for
              you in one click — you don't need Docker, an account, or any
              setup of your own. It gives better results than scraping
              DuckDuckGo, it can't be rate-limited the way scraping can, and
              the query never leaves your own network. It has to be on this
              machine or your own network — MemoryMap won't send searches to
              somebody else's instance, and the one it runs for you listens on
              127.0.0.1 only.
            
                                                      
            
                                                      
              
                                                      
                Let MemoryMap run SearXNG
                Checking…
              
                                                      
              
                                                      
                MemoryMap can start and stop SearXNG for you — settings and the
                JSON API are configured automatically, so there's nothing to
                edit.
              
                                                      
              
                                                      
              
              
                                                      
              
                                                      
                
                
                
                
              
                                                      
              
              
              
              
              
                                                      
              
              
                                                      
                What SearXNG reported
                
                                                      
              
                                                      
            
                                                      
            
                                                      
              Prefer to run it yourself?
              
                                                      
                SearXNG is a separate service, so MemoryMap runs it beside
                itself rather than inside itself. If you'd rather drive it
                yourself, it's a single command with Docker:

                search.formats in its settings.yml, then
